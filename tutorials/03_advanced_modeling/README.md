# Advanced Modeling

In this series, we'll dig into more advanced modeling patterns.

We'll assume familiarity with the concepts covered in the [Intro to Modeling][] tutorial, as well as familiarity with Kotlin.

Most of the lessons in this series are self-contained, but later lessons may build on earlier ones.
We'll call out when that's the case, so you can refer back to earlier lessons as needed.

By the end of this series, you should have an array of techniques to model more complex systems,
and the understanding to trade complexity of the model, accuracy, elegance, and performance against each other.

The aim of this series isn't to be opinionated about any one particular style.
Rather, it's to inform you of the options available to you and how to compare them.
